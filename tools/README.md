# 图集生成管线

把一张参考图变成协议图集（1536×2288，8 列 11 行，每格 192×208）。

**为什么不用 AI 生图**：88 帧之间角色必须完全一致，而生成模型最不擅长的就是帧间一致性——尾巴会变形、眼睛会漂移、体型会忽大忽小。这里的做法是**反查像素的确定性位移场**：同一份 alpha 与颜色，每帧用不同的连续位移场采样一次，所以帧与帧之间**只会动、不会变**。

## 流程

| 脚本 | 做什么 |
| --- | --- |
| `sprite.mjs` | 读 `src.webp` → 抠出角色 → 去白边（按 alpha 反预乘颜色）→ 连通域清理（去碎块、填小孔）→ 输出 `sprite.png`（RGBA）+ `sprite-meta.json` |
| `render.mjs` | 渲染核心。平滑位移场 + 反向映射 + 预乘双线性 + 2×2 超采样；导出 `loadSprite` / `renderCell` / `drawPlume` / `blowholeCell` |
| `actions.mjs` | 11 组动作的参数表（弯曲 / 胸鳍 / 尾鳍 / 喷水 / 仿射），`FRAME_COUNT` 与协议一致 |
| `build.mjs` | 铺 8×11 网格 → `spritesheet.png` + `pet.json`，并输出预览图 |
| `verify.mjs` | 逐格校验：alpha 包围盒、是否触格边（CLIP）、无效帧是否真的留空 |
| `zoom.mjs` | 把指定格放大拼图，肉眼复核 |

## 位移场要点

- **全局弯曲**：沿体轴方向的正弦位移，振幅随离头部距离增大 → 尾部摆幅最大、头部几乎不动。头部不动这点很重要，否则整只角色会"漂"。
- **局部形变**：胸鳍/尾鳍用高斯权重做局部旋转。
- **无切割**：位移场连续 ⇒ 结果一定连续，永远不会有图层接缝。
- **喷水**：唯一手绘元素。竖直水柱 + 12 颗扇形水花，用比本体更浅的蓝，否则会和头顶糊成一个角。

## 运行

```bash
npm i sharp          # 或在有 sharp 的项目里用 createRequire 引
node sprite.mjs && node render.mjs && node build.mjs && node verify.mjs
```

参考图不在此仓库。想重跑，把任意同风格的鲸鱼图命名为 `src.webp` 放进本目录——`sprite.mjs` 里的几何参数（缩放、偏移、喷口位置）是照着原图调的，换图需要重新调。
